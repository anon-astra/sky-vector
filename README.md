# Skyvector

Plain-language airspace desk: routes, terminal sectors, and sample weather. Published with GitHub Pages.

**Live:** https://anon-astra.github.io/sky-vector/

Ask things like “show me flights from Delhi to Mumbai”, “sector at Heathrow”, or “weather in Dubai”. Timetables and METARs on this site are illustrative, not live inventory or a clearance. Not for navigation.

Cloud wording help needs a server, so this Pages build answers with the on-page reader.

The previous live-radar edition (OpenSky snapshots, refreshed on a schedule) is preserved on the `radar-pages` branch.

## Publish

Pushes to `main` run **Publish Skyvector** and deploy the static build to GitHub Pages. Pages source is GitHub Actions, not a docs folder.
